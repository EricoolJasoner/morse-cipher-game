## 这是什么

Cipher Dispatch 是一个**网页端摩斯电码小游戏**，同时也是一个**可安装的离线 App**（PWA）。风格是 _Economist/Times_ 的编辑部排版 + 冷战作战室（war room）的仪表盘，混合了二战监听员的仪式感和赛博终端的数据密度。

- 不需要账号，不上传任何东西。
- 进度存在你自己浏览器的 localStorage 里，换设备不会同步。
- 装成 App 后可以**完全离线玩**。
- 专为 Eric 和他的朋友们设计，首关会用你自己的英文名当暗号。

## 怎么开始

### 第零步 · 验证身份

进入页面会看到一个红色的「SECURE ACCESS PROTOCOL · LEVEL IV」面板，右边是 Eric 的肖像。验证题是：

> Eric 是 __ 班的？

答案是 **12**（只有 Eric 的朋友才知道的暗号）。输入后按「进入游戏」，发报大厅、任务墙、波形屏才会全部通电。

### 第一步 · 录入你的代号

顶部「Operative Identity · 生成专属密码」把自己的英文名字输进去（只接受 A–Z，会自动大写）。右边会实时生成对应的摩斯码，第一关的目标也会自动换成你的名字。

### 第二步 · 发第一份电报

中间面板是作战终端。第一关是新手教程：

1. 先点左下角 **「播放姓名示例」**，系统会把你的名字用标准节奏发一遍。听清楚点（·）和划（−）的时长。
2. 听完后发报键会亮起琥珀色。
3. **按住空格键**或**按住发报键**，短按是点，长按是划，放开后停顿一下系统会自动确认这个字母。
4. 按正确节奏把名字打完，任务完成。

## 发报规则

| 符号 | 英文 | 按法 | 默认时长 |
|------|------|------|----------|
| · (点) | Dit | 短按 | 约 140 ms |
| − (划) | Dah | 长按 | 约 420 ms |
| (停顿自动切字) | — | 抬起后等一下 | 约 600 ms |

- 停顿超过「字母间隔」（默认 600 ms）系统会把当前的点划组合解码成一个字母。
- 例：`.` = E，`-.` = N，`...` = S，`-.-.`= C。
- 所有字母的标准码表可以在「Personal Morse Preview」里对照你自己名字的输出确认。

### 操作设备

- **电脑**：空格键按住 = 按发报键。键盘输入最稳定。
- **手机**：直接按住底部粘性的「SPACE 发报键」，松手自动判断点/划。
- **鼠标/触屏**：点住屏幕上的发报按钮也可以。

## 六场战役

任务墙（左侧 Campaign 栏）按顺序解锁，必须通关前一关才能进入下一关。每关标签说明了类型（编码 / 监听 / 博弈 / 干扰 / 终局）、环境、难度。

| # | 代号 | 类型 | 目标词 | 说明 |
|---|------|------|--------|------|
| 01 | 姓名报码 | 编码 Lv.1 | 你自己的名字 | 新手教程，必须先听示例。 |
| 02 | 午夜监听 | 监听 Lv.2 | HEART | 目标隐藏，先点「重放监听」听波形再回传。 |
| 03 | 敌台诱饵 | 博弈 Lv.3 | OPTIONC | 诱导你选 A 或 B，正确答案是第三方案。 |
| 04 | 雷暴滤波 | 干扰 Lv.4 | SHELTER | 监听片段有噪点干扰，按节奏回传。 |
| 05 | 真空延迟 | 编码 Lv.5 | FUTURE | 真空管机有延迟，需要提前预判节拍。 |
| 06 | 双时空中继 | 终局 Lv.6 | ALLYNODE | 高强度复合干扰，传奇机最配。 |

> 监听类关卡目标词显示为「待破译」，你要从监听片段和波形里自己听出来。

## 四代机型

右侧「Hardware · 机型仓」按通关数逐步解锁。不同机型有不同的手感，是游戏的深度玩法：

| 机型 | 解锁条件 | 特点 |
|------|----------|------|
| 第一代机械手键 | 起始 | 灵敏但躁动，抖动中等，适合练准度。 |
| 第二代真空管机 | 通 2 关 | 58 ms 系统延迟，要在节拍前下手。 |
| 现代数字终端 | 通 4 关 | 抖动极低 + 22% 自动纠偏，稳定但分数低。 |
| 传奇便携特工机 | 通 6 关 | 噪声最多，纠偏几乎为 0，但单关分数 +140。 |

**参数含义**（开发者/死磕党可以看）：

- `dotCutoff`：按键时长低于此值判为点，否则为划。不同机型略有差异。
- `letterGap`：停顿超过此值自动解码一个字母。
- `latency`：系统会从你的按键时长里「偷」走的毫秒数（真空管机吞半拍）。
- `jitter`：每次按键叠加的随机扰动（±）。
- `assist`：在点/划阈值附近时，系统把你的输入「吸」到标准值的概率。

## 评分与节奏辅助

### 实时指标（训练面板）

- **准确率 Accuracy**：初始 100%，每次错误 −11%，最低 40%。
- **节奏评分 Rhythm**：按准确率映射成 S/A/B/C。S 需要 ≥96%，A ≥88%，B ≥76%。
- **发报速率 Speed**：按每分钟发出的脉冲数计算。

### 单关分数公式

```
得分 = 420 + 准确率 × 7 + 速率 × 3 + 机型奖励
机型奖励：机械/真空 = 35，数字 = 90，传奇 = 140
```

完成一关后左下「操作日志」会记录分数，右侧总分累积。

### 节奏条

训练面板里那条琥珀色进度条显示「最近一次脉冲长度」，帮你感受自己的节拍是偏点还是偏划。标准节奏是 1 拍 = 点，3 拍 = 划，点划间的停顿 = 1 拍。

## § BUREAU DE CHIFFRES · 短句密码局

Hero 区下半部分的实验室。可以生成「我爱你/我恨你/你在干什么」这类中文短句的拼音摩斯码，也能直接输入英文/数字自由转码。

- 内置别名：「我爱你」→ `WO AI NI`，「我恨你」→ `WO HEN NI`，「你在干什么」→ `NI ZAI GAN SHEN ME`。
- 自由模式：输入 `I LOVE YOU` 会直接按字母生成；输入暂未内置的中文会提示请输拼音。
- 长度不限，可以当玩笑纸条发给朋友。

## 控制按钮

- **重放监听 / 播放姓名示例**：用音频把当前任务的标准摩斯码放一遍，同时在波形屏上滚动对应脉冲。
- **清空缓冲**：清掉当前这一关还没打完的输入，错太多时按这个从头来。
- **下一任务**：通关后进入下一关；未完成时会提示「请先完成当前任务」。

键盘快捷键：
- `Space` = 按住发报（只在焦点不在输入框里时生效）。

## PWA · 装成 App

### 桌面（Chrome / Edge）

1. 打开 https://ericooljasoner.github.io/morse-cipher-game/
2. 地址栏最右会出现一个「⊕ 安装」小图标，点它 → 安装。
3. 也可以走菜单：⋮ → 安装 Cipher Dispatch。
4. 装完后可以在开始菜单/dock 里找到，独立窗口运行。

### iPhone Safari

1. 打开网址。
2. 底部分享按钮 → 「添加到主屏幕」→ 完成。
3. 首次打开会进入全屏模式（不带浏览器地址栏）。

### Android Chrome

1. 打开网址。
2. 菜单 → 「安装应用」或「添加到主屏幕」。

### 离线能力

第一次打开后 Service Worker 会缓存所有资源（HTML/CSS/JS/图片/图标）。之后**断网也能玩**。进度、机型、总分都存在本地，不会丢。

## 进度与重置

- 进度键：`eric-morse-cipher-progress-v1`（localStorage）
- 包括：选择的机型、玩家名字、已完成关卡、总分、最佳连胜。
- 想清空进度：浏览器开发者工具 → Application → Local Storage → 删除上面那个 key，刷新页面即可。

## 技术栈 / 开发

完全原生，没有任何依赖：

- HTML + CSS（衬线 Cambria/Georgia + 等宽 Consolas）
- 原生 JavaScript（Web Audio API + Canvas）
- PWA：manifest.webmanifest + service-worker.js
- 托管：GitHub Pages

本地开发直接双击 `index.html` 就行，不需要构建。如果要测 Service Worker，需要用本地 HTTP 服务器（浏览器不允许 `file://` 注册 SW）：

```bash
npx http-server . -p 8080
```

然后访问 http://localhost:8080。
